# Diet Tracker

A local-first daily diet tracker using IndexedDB.

Features:
- Previous / next / today navigation
- Calories, protein, carbs and fat targets
- Water tracking
- Expandable nutrition details
- Meal containers with times
- Personal food library
- Custom foods
- Quantity-based nutrition calculation
- Copy previous day
- Clear day
- Persistent IndexedDB storage

Open `index.html` directly or serve the folder with a local web server.
